## 📌 Sobre o Projeto

O **Vila Belmiro Viva** é um portal web comunitário que centraliza informações sobre o bairro da Vila Belmiro, em Santos/SP. O objetivo é reunir, em um único canal digital gratuito e acessível, dados sobre comércio local, eventos, história do bairro, trânsito em dias de jogos e tour virtual pelo Estádio Urbano Caldeira.

O projeto foi desenvolvido como parte da disciplina **Projeto Integrador em Computação II (PJI240)** da Universidade Virtual do Estado de São Paulo (UNIVESP), seguindo a metodologia do **Design Thinking** (Ouvir, Criar e Implementar).

---

## 🚀 Funcionalidades

*   **Página inicial:** Vídeo de fundo e navegação por abas (SPA).
*   **Explorar:** Card com o próximo jogo do Santos FC e navegação para as demais seções.
*   **Comércio Local:** Mapa interativo (Leaflet) com lista de comércios reais e pinos coloridos por categoria.
*   **Santos FC:** Link para o site oficial e **Tour Virtual 3D** (Street View) dentro do estádio e no portão principal.
*   **Trânsito:** Mapa de trânsito ao vivo (Waze), informações sobre bloqueios de ruas, credenciais para moradores e imagem das vias interditadas.
*   **Bairro:** História e curiosidades da Vila Belmiro, além de um mural com eventos semanais (Feira Livre e Ensaio da Torcida Jovem).
*   **Barra superior:** Data, clima (API Open-Meteo) e relógio em tempo real.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
| :--- | :--- |
| **Python + Flask** | Framework web (backend e rotas) |
| **HTML5 / CSS3** | Estrutura e estilização (Design System com variáveis CSS) |
| **JavaScript** | Interatividade (abas, mapa, clima, contador) |
| **Leaflet.js + OpenStreetMap** | Mapa interativo (gratuito, sem API key) |
| **Open-Meteo API** | Dados de clima em tempo real (gratuita) |
| **Google Maps Embed** | Tour Virtual (Street View) |
| **Waze Embed** | Mapa de trânsito ao vivo |
| **Git / GitHub** | Controle de versão e hospedagem do código |
